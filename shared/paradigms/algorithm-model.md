# 算法与模型研究

## 适用

用于算法、机器学习模型、优化方法、信号处理和模式识别等贡献。只对相应贡献启用，不要求整本论文都满足同一种实验形态。

## 最低证据

- 明确任务、输入输出、假设、训练/推理阶段和评价范围。
- 给出数据来源、划分、预处理、指标、实现环境、关键超参数和随机性处理。
- 基线与当前问题相关，采用相同或可比的数据、预算和评价协议；不可比之处明确披露。
- 主结果能支持核心主张；模块必要性由适当的消融、对照或替代方案验证。
- 仅在主张需要时检查复杂度、效率、鲁棒性、敏感性、泛化或不确定度，不机械要求全部实验。
- 提升说明绝对值、百分点或相对变化，平均值说明模型、数据和重复范围。
- 结论限制在实际测试的模型、数据、任务和条件内。

## 主张边界

性能提升本身不能证明内部机制、普适性、真实部署效果或因果关系。归因、消融和组件移除支持的结论强度应与设计相符。
