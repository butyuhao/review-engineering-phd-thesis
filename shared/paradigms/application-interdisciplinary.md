# 应用与交叉研究

## 适用

用于智能教育、医学工程、工业智能、智慧城市、农业工程、人因和其他将工程方法用于具体场景的贡献。

## 最低证据

- 明确应用问题、相关主体、场景约束、成功标准和技术能够影响的环节。
- 说明数据与场景代表性，区分训练对象、模拟对象和真实使用者。
- 技术性能与应用效果分别评价，避免用一个层面的指标替代另一个层面的结论。
- 仅当结论依赖人工评分、专家判断、模型裁判或模拟参与者时，报告评价者类型、数量、资格、样本分配、材料、量表、一致性和争议处理。
- 准确命名自动评估、模型裁判、普通标注者、领域专家、模拟参与者和真人用户。
- 按场景风险讨论隐私、安全、伦理、公平性、责任边界和部署条件。

## 主张边界

模拟对话、模型评分或自动指标不能写成真实临床、教学或工程部署效果。缺少真人、专家或长期观察时，应明确外部效度边界。
