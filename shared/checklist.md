# 中文工科博士论文初稿后审查清单

这份清单用于“论文已经有完整初稿之后”的系统检查。它不是统一写作模板，也不要求不同学科使用相同标题。先提取论文自己的局部标准，再判断结构、术语、证据和版式是否自洽。

## 0. 锁定对象与事实来源

- 确认本次审查的是哪一个项目、哪一个模板、哪一个 PDF，记录文件修改时间。
- 找到主文件、章节、摘要、参考文献、图目录、附录、致谢、成果页和模板配置。
- 源码是可编辑事实来源；最新编译 PDF 是最终可见版式来源；主结果表和原始实验记录是数字事实来源。
- 不把旧 PDF、旧模板、参考论文或生成的 `.bbl/.toc/.lof/.lot` 当作主要编辑对象。
- 查看工作区状态，避免覆盖作者尚未提交的修改。

## 2. 研究框架与贡献对应

- 背景提出的现实/理论需求能否自然导向研究问题，而非先介绍技术再硬接应用。
- “现有不足”是否具体、可被后文解决，避免只写“精度不高、效率不足、研究较少”。
- 挑战、研究内容、创新点和研究章是否数量对应、顺序对应、命名对应。
- 框架图是否让相邻领域读者看懂“为什么做、做什么、怎么做、如何验证”，而非堆缩写。
- 框架图中的箭头是否表达真实依赖；前一章是否确实为后一章提供数据、机制、约束、模块或验证。
- 每项贡献能回答：解决什么问题、为何现有方法不足、提出什么、用什么证据、得到什么结论、边界是什么。
- 应用章节不能仅靠叙述挂接；应明确使用或验证前文的方法、系统、规律或设计原则。
- 第一章组织架构、各章章前段、引言末段、本章小结和末章总结应使用同一套贡献名称。

高频错误：章标题改过，但摘要、框架图、目录说明、caption、末章和答辩材料仍保留旧名。

## 3. 中英文摘要与关键词

- 按句对齐问题、挑战、研究主线、贡献、数据、方法、实验范围、数字、结论和应用边界。
- 每项贡献采用“问题 -> 方法 -> 证据 -> 结论”的紧凑结构，不只列工作过程。
- 所有百分比、样本数、模型/工况数、指标值、计算量和提升幅度回到主表复算。
- 明确百分比是绝对提升还是相对提升，平均值的模型/数据/工况范围是什么。
- 英文摘要自然分句，避免一个句子承载问题、方法、实验和结论四层从句。
- 中英文贡献小标题与章标题或认可的简写一致。
- 关键词能覆盖理论/对象、核心方法和应用，不放正文边缘概念。
- 缩写在中英文摘要中分别首次定义；英文大小写和连字符统一。
- 摘要中的“首次、证明、显著、真实、通用、机制、因果”有对应证据。
- 摘要不引用图表或章节，不依赖读者先读正文才能理解。

## 4. 第一章：背景、意义、问题与组织

- 背景从宏观需求逐步收束到具体研究对象，不要过早抛出未解释的方法名或数据集。
- 政策、白皮书、标准、行业数据和快速变化事实使用最新权威来源，且引用内容真正支持句子。
- 理论意义说明补充了什么知识、模型或解释；实践意义说明解决什么工程需求，避免重复贡献列表。
- 选择理论框架、技术路线、材料体系、模型族或评价体系的理由明确且可辩护。
- 研究现状与问题之间有逻辑桥梁；问题不是凭空列出。
- 创新点写“新在哪里”，与“完成了哪些工作”区分。
- 组织架构准确描述最新章节，不引用已删除/降级的小节。
- 章前引入、1.1 背景和贡献部分分工明确，避免同一段动机重复三次。

## 5. 理论基础、技术背景与相关工作

- 理论基础解释后文真正使用的概念、假设、模型、量表、标准或机理。
- 技术背景提供理解方法所需的知识，但不提前写成本人的方法章。
- 相关工作按问题、技术路线或证据类型组织，不按论文逐篇罗列。
- 每个相关工作块最终收束到明确研究缺口，并能对应后续贡献。
- 全书系统相关工作的位置清晰；若集中到一章，研究章只保留必要缺口，不重复整段综述。
- 小标题符合中文博士论文层级，不机械复制英文论文的 paragraph/subsubsection。
- 不制造缺乏公认来源的分类来增强形式感；答辩中无法解释的分类应重写为自然叙述。
- 引用紧跟所指方法、理论、数据、标准或论断；多个名称与多个引用应一一对应。
- 理论概念第一次出现时说明与本文变量、实验或章节的关系。
- 第二章小结总结本章为后文提供的概念与研究定位，不再重复大段相关工作。

## 6. 章节结构与跨章衔接

- 每个研究章至少形成：问题/动机、对象或准备、方法/系统/工艺、验证、结论；标题可按学科调整。
- 数据集、试样、实验平台、输入条件和评价指标在依赖它们的结果之前定义。
- 主结果先于细分分析；讨论建立在已展示的数据或图表上。
- 章引言说明本章在整篇中的作用、前章提供了什么、本章解决什么，但不使用未定义缩写。
- 章小结包含“做了什么 + 证据是什么 + 得到什么”，不只是复述目录。
- 末章按贡献总结核心发现，不引入正文未出现的新结果。
- 展望从各贡献的真实限制出发，每段深入一两个可执行方向，避免罗列热门名词。
- 一个 section 下只有一个 subsection 时检查是否需要提升层级或拆成平行项。
- 各研究章在功能上尽量平行，避免某章叫“准备工作”、另一章同类内容叫“相关技术”而无理由。

章节重排后专项检查：

- `前文、后文、上述、如下、上一节、下一节、见第 X 章` 的方向是否仍正确。
- 概念、符号、方法和数据是否先定义后使用。
- 被删除/降级标题的 label 和 `ref` 是否残留。
- 章开头与被移动正文是否重复动机、定义或贡献。
- 图表首次引用与浮动体是否仍在合理位置。

## 7. 方法、实验与结论闭环

对每项贡献画一条证据链：

`研究问题 -> 可检验假设/目标 -> 方法设计 -> 实验或推导 -> 观察结果 -> 结论 -> 适用边界`

检查：

- 问题定义与本章宣称解决的挑战一致。
- 方法每个核心模块都能回溯到动机或缺口，不是无解释堆叠。
- 方法图、正文、公式、算法和实现采用同一符号、模块名和处理顺序。
- 实验设置足以复现：数据/试样、划分、设备、环境、参数、重复次数、统计方法。
- 基线、对照、消融和工况设置与目标主张匹配且公平。
- 评价指标在主结果前定义，方向（越大/越小越好）、单位和计算方式明确。
- 人工评价写明人员类型、人数、资格、样本分配、指南、一致性与争议处理。
- 模型裁判、模拟智能体、普通标注者和领域专家严格区分。
- 每个结果小节明确引用正在分析的图/表，结论能从对应数据直接得到。
- 讨论不只重复结果，而是解释原因、比较已有研究、分析失败案例和边界。
- 局限性与未来工作对应实际缺口，不用未来工作补救当前核心证据缺失。

主张边界：

- 删除节点/模块后性能变化通常称消融或干预分析，不自动等于严格因果证明。
- 模拟环境中的应用任务不能直接称真实部署或真实用户效果。
- 单一数据/材料/模型/地区结果不能直接称通用或普适。
- “显著”若表示统计显著，应给检验；否则改为“明显”或直接报告数值。

各范式的额外证据要求见 `discipline-adaptation.md`。

## 8. 术语、缩写与语言

- 建立首选中文、首选英文、缩写、首次定义、允许简称和旧词清单。
- 上位术语与下位术语关系稳定，例如“部件/节点/模块”不能随意互换。
- 方法、数据集、设备、材料、标准和指标的大小写、连字符、空格一致。
- 中文首次出现可写“中文术语（English Term, ABBR）”，后文按既定规则使用。
- 同一概念不要有时纯英文、有时中文、有时中英混写。
- 中文正文中的英文专名大小写按正式名称，不因置于括号内就全部小写。
- 少用层层嵌套长句；转折、因果、递进连接词应反映真实逻辑。
- 避免连续使用“在此基础上、后续、进一步、这说明”等空泛衔接。
- 段首加粗标签、paragraph 和 bullet 只在确实帮助定位且全章风格一致时使用。
- 中文引号、书名号和括号成对，避免左右引号同形。
- 中文段落用全角标点；数字、英文缩写、单位之间的空格遵循模板和国家标准。
- 查找替换后检查乱码、误伤专有名词、公式、引用标题和 bib。

## 9. 符号、公式与算法

- 每个符号首次出现即定义，给出取值域、维度、单位或集合。
- 同一符号不用于两个概念；同一概念不在不同章节无说明地换符号。
- 标量、向量、矩阵、集合、算子、随机变量的字体规则一致。
- 公式与句子连读，逗号或句号按语法放置；不要机械地全部无标点。
- 量纲、单位、上下标、正负号、坐标系和边界条件一致。
- 关键推导没有跳步到无法验证，附录中的推导在正文有定位。
- 公式编号只给正文需要引用的公式；所有 `eqref` 有目标。
- 算法输入、输出、初始化、终止条件和返回值完整。
- 伪代码变量与正文、公式和实现描述一致，算法标题语言符合模板。
- 算法不是把自然语言方法段机械改成逐行列表；应表达可执行过程。

## 10. 图、表与 caption

每个主要图、表、算法都检查：

- 正文在出现前或附近明确引用，且引用句说明读者应看什么。
- 浮动体靠近首次实质分析，不集中在章末，也不在解释前孤立占页。
- 编号、label、ref、图/表目录条目正确，无重复或失效 label。
- caption 自包含但不重复正文整段；术语与正文一致，缩写必要时解释。
- caption 中没有无意的 `textbf`、`textsc`、原始 LaTeX 或多余英文格式。
- 全文 caption 末尾标点采用一种规则；修改后 `.lof/.lot` 也不残留旧格式。
- 图中文字在 A4 打印尺寸下可读，颜色在灰度/色觉条件下仍可区分。
- 坐标轴、单位、图例、样本数、误差或统计含义完整。
- 表格不超出版心，列宽按内容分配，先优化结构再整体缩字号。
- 数值精度、单位、最佳/次佳标记一致；非比较列不加粗/下划线。
- 表格独占一页时检查能否让引入或分析文字合理流入，但不强行破坏可读性。
- 跨页/拆分表使用清楚的“（一）（二）”或“续表”，并与完整样例表区分。
- 图片形式的表格仍应保证可搜索性、清晰度和边框风格符合要求。
- 附录中的核心证据若正文实质依赖，应移到正文或提供充分摘要。

## 11. 浮动体与 PDF 版面

- 检查所有章开头、章末、图表密集页、强制定位附近和附录过渡页。
- 无超宽表、裁切图片、`Float too large for page`、孤立 caption 或标题落单。
- 无大量浮动体堆在章末，无异常空白页或大块空白。
- 页眉、页脚、页码、章节起始页和单双面空白页符合模板。
- 标题层级、段前段后、首行缩进、列表缩进和段首标签间距一致。
- 中文/英文摘要没有因一两行溢出破坏模板要求。
- 图表清单、目录、参考文献和附录起始位置正确。
- 章节长度失衡先判断是否因论证缺失，不为凑页数拉大间距或让表格独占页。

## 12. 交叉引用、引用文献与外部事实

- 编译后无 `??`、undefined reference/citation、重复 label 或错误超链接。
- 每个主要图表算法有正文引用；每个正文 ref 有存在的目标。
- `main.tex` 实际加载的 bib 文件明确，不长期手改生成的 `.bbl`。
- 一句话列多个方法/理论时，每个引用紧跟对应对象，避免全部堆在句末造成映射不明。
- 外部事实、政策、标准、行业数据和评价协议有来源。
- 政策、标准、软件版本、模型参数和近年论文属于时效信息，终检时查权威原始来源。
- arXiv 已正式发表时，在核实后更新出版信息；不从相邻条目猜 venue、DOI 或页码。
- 自引比例、参考文献格式、中文/英文文献类型满足学校规则。
- 未引用 bib 的清理是可选维护动作，不应在无备份或未确认时自动删除。

## 13. 最终 PDF 完整性

- 文件可打开，页数、文件名、大小、加密状态符合提交要求。
- 页面为学校要求的 A4 或指定尺寸，字体嵌入，中文可搜索复制。
- 无乱码、替换字符、黑框、公式缺字、图片低清或链接异常。
- 封面、中英文题名页、声明、摘要、目录、图表清单、正文、参考文献、附录、致谢、成果页顺序正确。
- 中文与英文封面的题名、作者、导师、院系、专业、学位和日期一致。
- 视觉抽查至少覆盖：封面、两版摘要、目录、每章首尾、最宽表、最大图、附录、致谢和成果页。
- 扫描器报告的低文本页逐页判断：合法封面/章间空白，还是异常空白或整页浮动体。

## 14. 盲审与明审

- 先确认本次提交类型，再检查内容；不要把合法匿名占位误报为错误。
- 查模板中的 `anonymous`、`blind`、`notanonymous`、`if...` 等开关及条件分支。
- 盲审版检查封面、致谢、成果作者、项目编号、文件属性、PDF metadata、页眉和自引措辞。
- 明审/终稿检查真实姓名、学号、导师、学院和成果信息是否恢复且一致。
- 中英文封面可能由不同条件分支生成，要分别验证。
- 学校当年匿名范围优先于经验规则；不确定时列为未验证项。

## 15. 字数与章节体量

- 同时区分：LaTeX `texcount`、Word-like 源码估计、PDF 可见文本估计、学校查重系统口径。
- 报告数字时写清是否含摘要、参考文献、附录、致谢、图表文字和英文。
- 学校行政表格有官方统计时使用官方口径，不用脚本估计替代。
- 按章统计用于识别论证失衡，不以“和某篇论文一样长”为目标。
- 章节偏短时优先补问题定义、方法细节、实验设置、结果分析、局限和证据，而非拉版面。

## 16. 学位材料与成果信息

- 学位申请理由、导师评语、政治思想、课程、科研成果和论文完成情况符合表格提问对象。
- 不编造党员身份、学位经历、实习、项目角色、奖项或成果状态。
- 硕博连读若未授硕士学位，不写“已获硕士学位”。
- 论文作者顺序、共同一作、已发表/录用/在投、会议期刊名称和时间准确。
- 专利区分申请、公开、授权；项目角色和贡献不过度包装。
- 论文题名、贡献数量、关键数字与最终论文一致。
- 需要简洁时可用正式会议/期刊缩写，但首次出现或行政要求时给全称。

## 17. 自动扫描结果的使用

- 先运行 LaTeX/PDF 扫描器，再逐条查看上下文。
- 机械扫描擅长发现：乱码、草稿标记、标签、bib key、未引用图表、caption/paragraph 风格混用和低文本页。
- 机械扫描不擅长判断：创新性、实验公平性、公式正确性、引用是否真的支持论断、浮动体视觉质量。
- 不把告警数量当论文质量分数；同一模板宏可能造成系统性误报。
- 报告中只保留经人工核实的发现，自动输出可作为附录或验证记录。
