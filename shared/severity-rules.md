# 严重度与检查状态

## 1. 先标状态，再定严重度

每个检查项先使用以下状态：

- `candidate`：自动规则命中，尚未核实；
- `confirmed`：已核对活动源码、当前编译结果、PDF 页面、原始结果或权威来源；
- `not_verified`：输入、工具或外部证据不足；
- `not_applicable`：不适用于该论文、贡献或本次审查范围。

只有 `confirmed` 项才能成为正式 P0-P3 问题。自动扫描器只给出候选优先级、置信度、误报边界、确认动作和建议严重度范围，不单独决定最终 P0/P1。

## 2. 判据术语

- **明确**：给出可定位的对象、条件、输入输出或评价口径，而非只能从上下文猜测。
- **可复现**：具备复现核心结果所必需的数据或试样、处理、环境、参数、重复和统计信息；不能公开的内容说明获取和使用条件。
- **公平比较**：使用相同或可比的数据、划分、预处理、资源预算和评价协议；差异无法消除时明确披露并限制结论。
- **核心主张**：出现在摘要、创新点、贡献列表或末章结论，并影响论文主要学术结论的主张。
- **主要图表**：支撑核心主张或被正文用于得出关键结论的图、表或算法，不等于全部浮动体。

## 3. P0：确认的提交阻断

- 实际提交 PDF 无法使用、缺失关键页面、关键内容不可读或明显损坏；
- 盲审提交物确认泄露学校禁止的身份信息；
- 作者、题名、学位类别等核心行政信息确认错误；
- 核心数据、公式、图表或计算错误使主要结论失效；
- 当前活动版本和 PDF 中确认存在未解析引用、缺失对象或错误跳转，导致关键内容不可理解。

单纯正则命中、未加载源码、PDF 文本提取异常或模板占位不能直接判为 P0。

## 4. P1：确认的重大问题

- 核心贡献在摘要、第一章、研究章和末章之间存在改变范围、方法身份、证据强度或结论方向的实质矛盾；
- 核心主张明显超出证据类型或适用范围；
- 方法、数据、实验设置或评价协议缺失到无法理解或验证核心工作；
- 主要图表、公式或实验结果无法支持论文依赖它得出的核心结论；
- 核心章节与研究主线脱节，且论文没有给出合理关系。

## 5. P2：局部质量问题

- 术语、符号、缩写、单位、标题或引用映射存在局部不一致；
- 复现信息、解释、讨论或限制不完整，但不直接推翻核心结论；
- 图表、公式、caption 或章节衔接影响阅读和核查，但仍可理解；
- 外部事实、出版状态或标准版本需要核实，且会影响正文准确性。

## 6. P3：可选优化

- 不影响正确性、证据链、复现、可审阅性和学校要求的语言精炼或版面美化；
- 有明确收益、不会引入新风险且不改变论文判断的可读性增强。

不要默认把“补更多实验、更新更多文献、换一种标题风格”列为 P3。必须说明具体收益和风险。

## 7. 自动候选项

候选项至少包含：

```text
检查 ID：
状态：candidate / not_verified
候选优先级：high / medium / low
置信度：high / medium / low
位置：
触发证据：
可能误报原因：
人工确认动作：
确认后的严重度范围：
```

## 8. 提交判断

- P0 必须关闭后才能给出“具备提交条件”的结论。
- P1 应修复，或用新证据证明其不成立/可降级。仅写“作者接受风险”不能使其消失；明确豁免时仍保留剩余重大风险说明。
- 未执行的视觉、外部事实、原始数据或匿名检查列入 `not_verified`。
- “未发现 P0/P1”只表示在本次证据覆盖内未确认，不等于论文完全没有问题。
