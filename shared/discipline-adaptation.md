# 学科与研究范式适配

## 使用原则

中文工科博士论文共享一条基本论证链：

`现实或理论问题 -> 现有不足 -> 研究问题 -> 方法/系统/工艺/模型 -> 证据 -> 结论与边界`

但不同学科对“证据充分”的定义不同。审查前先为每个研究贡献标注一种或多种范式，不要按论文所属学院一刀切。一章可以是算法研究，下一章可以是系统实现或应用验证。

## 1. 算法或模型研究

常见于计算机、人工智能、信号处理、优化、模式识别。

至少检查：

- 任务、输入输出、假设和评价范围是否明确。
- 数据集、划分、预处理、指标和实现设置是否可复现。
- 基线是否充分且设置公平，是否使用相同数据和预算。
- 主结果之外是否有必要的消融、敏感性、复杂度、鲁棒性或泛化分析。
- 提升是否报告绝对值/相对值、方差或显著性，比较方向是否正确。
- 结论是否限制在测试过的模型、数据和条件内。

不能仅凭性能提升声称：解释了机制、具有普适性、适用于真实部署或形成因果关系。

## 2. 系统或软硬件研究

常见于计算机系统、电子工程、通信、自动化、嵌入式、机器人、仪器。

至少检查：

- 需求、约束、接口和设计目标是否明确，系统架构能否回溯到这些需求。
- 模块边界、数据流、控制流、软硬件环境和关键实现是否可理解。
- 是否有原型或实物实现，而非只停留在框图。
- 是否评估端到端延迟、吞吐、能耗、资源、可靠性、扩展性或实时性等关键指标。
- 与已有系统比较时，工作负载、硬件条件、数据规模和测量方式是否等价。
- 单模块指标提升是否真正转化为系统级收益。

不能仅凭模块仿真声称完成系统落地，也不能用算法准确率替代系统可用性证据。

## 3. 实验或工艺研究

常见于材料、化工、能源、环境、制造、生物医学工程。

至少检查：

- 材料来源、试样制备、设备型号、工艺参数、校准和对照组是否完整。
- 样本量、平行实验、重复次数、误差条、统计方法和不确定度是否充分。
- 表征方法是否能支持结构、性能和机理结论，是否存在证据跳跃。
- 实验条件、单位、有效数字和测试标准是否一致。
- 原始现象、经验关联、解释假设和机理结论是否分层表述。
- 涉及人体、动物、危险材料或敏感数据时，伦理、安全与来源是否合规。

不能把单次实验、相关性或表征图直接写成“证明机理”；更稳妥的表述是“结果表明”“支持该解释”或“提出可能机制”。

## 4. 理论或建模研究

常见于控制、力学、土木、水利、交通、工程数学和多物理场建模。

至少检查：

- 基本假设、边界条件、初始条件、坐标系和适用尺度是否明确。
- 符号、量纲、单位和正负号约定是否一致。
- 关键推导、定理、算法收敛性或数值离散是否完整。
- 模型是否通过解析解、数值算例、仿真、试验或工程数据验证。
- 参数识别、网格/步长无关性、稳定性、敏感性和误差来源是否说明。
- 适用范围、失效条件和简化假设造成的限制是否明确。

不能以“拟合良好”替代物理合理性，也不能把未验证的边界外推写成普遍规律。

## 5. 应用或交叉研究

常见于智能教育、医学工程、工业智能、智慧城市、农业工程、人因工程。

至少检查：

- 应用问题、利益相关者、场景约束和成功标准是否真实且明确。
- 数据和场景是否具有代表性，训练/模拟对象与真实使用者是否区分。
- 技术性能与应用效果是否分别评估，不能互相替代。
- 涉及用户效果的结论是否有真人、领域专家、长期观察或合理的外部效度证据。
- 自动评估、模型裁判、模拟参与者、普通标注者和领域专家是否准确命名。
- 隐私、安全、伦理、公平性、责任边界和部署条件是否讨论。

不能把模拟对话或模型评分写成真实临床、教学或工程部署效果；缺少真人和专家时应明确局限。

再检查：

- 各贡献的证据标准是否按范式变化，而非整本使用同一套指标。
- 论文是否解释算法、系统、实验、理论和应用章节为何属于同一研究主线。
- 前一贡献是否为后一贡献提供了真实输入、约束、方法或验证，而非只在叙述上连接。
