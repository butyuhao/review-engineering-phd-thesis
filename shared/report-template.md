# 最终审查报告模板

## 审查对象

- 源码：绝对路径、Git 分支、提交号及工作区是否干净。
- PDF：绝对路径、修改时间、页数和 SHA-256。
- 提交类型：预审、盲审、明审、归档或其他。
- 证据边界：哪些内容来自源码、最终 PDF、实验记录或外部权威来源。

如果远程仓库不可访问、PDF 并非由当前提交编译，或工作区包含未提交正文修改，必须在结论前说明，不能把旧版本审查结果套到新文件上。

## 结论

一句话说明是否发现 P0/P1，以及当前是否具备提交条件。不要在未完成 PDF 视觉检查、盲审核对或关键事实核验时直接说“可以提交”。

## 提交前必须处理

```text
[P0/P1] 问题标题
位置：PDF 第 X 页 / 第 X 章 / 图 X.X / path:line
证据：原文、数值、引用关系或可见版面
影响：对评审、复现、结论或行政受理的影响
建议：明确修改动作或替换文字
验证：重新编译后应满足的条件
```

若没有 P0/P1，明确写“未发现确定的提交阻断或明显重大问题”，不要用“完全没有问题”。

## 建议修正

列出 P2，一项只讲一个根因；同类术语或 caption 问题可合并并附代表位置。

## 可选优化

仅列真正有价值的 P3。临近提交时可以省略。

## 已通过的关键检查

只列对提交判断有帮助的项目，例如：

- 中英文摘要的四项贡献和关键数字一致。
- 所有主要图表均有正文引用。
- PDF 为 A4，未发现 `??` 或可见乱码。
- 盲审/明审模式与本次提交类型一致。

## 未验证与剩余风险

- 未能重新编译、缺少最终 PDF、外部文献事实未联网核实等。
- 自动扫描不能覆盖的视觉问题、复杂宏、公式正确性和学科创新性。

## 修改后的完成门槛

- P0 全部关闭。
- P1 已修复或由作者明确接受风险。
- 中英文题名、摘要、贡献、数字和关键词一致。
- 研究框架在摘要、第一章、框架图、各章和末章闭环。
- 交叉引用、引用文献、主要图表、公式和算法完整。
- 受影响页面已在最终 PDF 中视觉复核。
- 盲审/明审信息、成果状态和学位材料与事实一致。

## 示例摘要

```text
结论：未发现 P0；发现 2 项 P1，修复后再提交。

[P1] 英文摘要的性能提升数字与中文摘要不一致
位置：中文摘要第（2）点；英文摘要第（2）点
证据：中文为 12.6%，英文为 16.2%
影响：核心结果前后矛盾，评审可直接发现
建议：回到主结果表核实正确值，并同步两版摘要、第一章和总结
验证：全局检索两个数字，确认只保留经主表验证的数值
```
