# 论文审查报告模板

## 审查范围

- 对象：实际读取的源码、章节或 PDF；可记录路径、时间或版本，但不强制 Git。
- 目标：完整初稿、单章、摘要专项、终稿 PDF 或其他明确任务。
- 证据：活动源码、当前 PDF、编译日志、主结果、原始记录、学校要求、外部权威来源。
- 未覆盖：未提供或未执行的视觉、实验、外部事实、匿名和行政检查。

## 结论

一句话说明在本次证据覆盖内是否确认 P0/P1，以及当前判断的资格条件。证据不足时写“尚不能确认”，不要把自动扫描无告警等同于可以提交。

## 正式发现

按 P0-P3 排序，只放 `confirmed` 项：

```text
[P0/P1/P2/P3] 问题标题
状态：confirmed
置信度：high / medium / low
位置：PDF 第 X 页 / 第 X 章 / 图表 X.X / path:line
证据：原文、数值、引用关系、可见版面或原始记录
影响：对主张、复现、评审、阅读或行政受理的具体影响
建议：最小可执行修改
验证：修改后如何证明问题关闭
```

同一根因造成多处表现时合并报告，并给出代表位置或完整位置清单。

## 候选与未验证

自动命中但尚未核实的内容不得混入正式发现：

```text
[candidate/not_verified] 检查 ID
优先级与置信度：
位置与触发证据：
可能误报原因：
确认动作：
确认后的严重度范围：
```

## 已通过的关键检查

只列实际核对且影响结论的项目，例如核心贡献语义可追溯、关键数字与主表一致、主要图表支持对应结论。不要把未执行的检查写成已通过。

## 完成门槛

- P0 全部关闭；
- P1 已修复、被证据否定/降级，或报告明确保留豁免后的剩余重大风险；
- 受修改影响的贡献映射、数字、引用和 PDF 页面已复核；
- 所有 `not_verified` 项已明确，不用“完全没有问题”掩盖证据边界。
