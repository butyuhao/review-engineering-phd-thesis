# Profile：最终 PDF 与提交物

## 启用条件

仅当用户要求检查当前/最终 PDF、提交版、归档版、页数或版式时启用。学校规格未提供的项目标为 `not_verified`，不自行假定 A4、页边距、字体或页数要求。

## 检查

- 锁定实际 PDF，记录路径、修改时间和页数；只有需要版本核验时记录 SHA-256。
- 按学校要求核对页面尺寸、装订边、封面、页码、目录、摘要页数和必备页面。
- 视觉检查关键页面、主要图表、公式、目录与章首页是否裁切、超宽、重叠、字号不可读或出现异常空白。
- 检查 PDF 是否可打开、加密状态是否符合要求、字体和文本层是否满足学校可搜索/复制要求。
- 文本提取异常只作为候选；必须渲染确认视觉乱码后再定级。
- 低文本页只用于导航视觉抽查，封面、章间页和整页图片可能合法。
- “PDF 可提取文本量估计”不能当作 Word、`texcount`、查重系统或学校官方字数。

## 工具

```bash
python3 scripts/scan_pdf_text.py thesis.pdf
python3 scripts/scan_pdf_text.py thesis.pdf --expected-page-size A4
```

输出覆盖矩阵必须区分自动元数据、PDF 视觉、编译日志、外部要求和当前不可验证项。
