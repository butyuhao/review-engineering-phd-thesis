# 检查中文工科博士论文

## 目标

按“能否提交”的标准审查已有完整初稿的中文工科博士论文。优先识别会影响外审、答辩、复现和行政受理的问题，不把某一学科的术语或章节模板强加给其他工科论文。

核心方法：**先提取论文自己的局部标准，再检查全文一致性与证据充分性。** 自动扫描只提供机械风险线索，不能代替人工学术判断。

## 必须读取的共享规则

整本终检、跨章检查或提交前审查时，先完整读取：

- `../shared/checklist.md`
- `../shared/discipline-adaptation.md`
- `../shared/severity-rules.md`
- `../shared/report-template.md`

单点任务只读取 checklist 对应部分和严重度规则。`shared/` 是唯一规则来源，不在本文件复制另一套清单。

## 工作流

1. 锁定最新论文目录、主文件、参考文献、最终 PDF 和本次提交类型，防止误审旧模板或旧 PDF。
2. 提取中英文题名、总体问题、研究主线、挑战、贡献、章标题、方法/系统/工艺、数据/试样、指标、符号、缩写和旧术语，形成局部标准表。
3. 对每项贡献分别标注算法/模型、系统/软硬件、实验/工艺、理论/建模、应用/交叉一种或多种范式，并应用对应证据要求。
4. 有源码或 PDF 时运行：

```bash
python3 ../scripts/scan_latex_thesis.py /path/to/thesis --term '旧术语=新术语'
python3 ../scripts/scan_pdf_text.py /path/to/final.pdf
```

5. 人工检查顺序：提交完整性与匿名 -> 框架和摘要 -> 方法证据闭环 -> 术语符号与图表引用 -> PDF 版式与行政材料。
6. 审阅请求先按 P0-P3 报告经核实的问题；每项包含位置、证据、影响、修改动作和验证方式。
7. 用户要求修改时做定向改动，重新编译/导出，复扫旧词和引用，并视觉检查受影响页面。

## 纪律

- 外部政策、标准、出版状态、会议期刊和创新性表述先查权威来源。
- 消融、相关和敏感性分析不能自动写成因果或机理证明。
- 模拟对象、模型裁判和自动评估不能写成真人或领域专家验证。
- 全局替换前排除公式、专名、引用标题和 bib，修改后搜索旧词。
- 封面匿名占位先检查盲审开关，不误报；真正的身份泄漏按 P0 处理。
- 临近提交时先解决 P0/P1，不用低价值润色淹没作者，也不做高风险大改。

## 输出

使用 `../shared/report-template.md`。先给提交结论，再列问题。若未发现 P0/P1，也要说明未验证事项和剩余风险，不能仅凭自动扫描说“完全没有问题”。
